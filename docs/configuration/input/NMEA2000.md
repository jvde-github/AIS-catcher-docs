AIS-catcher can read AIS messages from an NMEA2000 socketCAN interface (Linux only). Frames sent from this machine, such as AIS-catcher's own NMEA2000 output, are not read, so a virtual `vcan` interface fed on the same machine shows nothing. NMEA2000 frame lines from a gateway can also be read over TCP, on any platform: `-t n2k://host:port`.

```bash
AIS-catcher -i can0
```
